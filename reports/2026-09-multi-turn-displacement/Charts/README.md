# Charts

Charts for **Study #24 — It Recommends You First. By Turn Four, It's Moved On.**

## Included charts

- `conversation-decay.svg` — cohort-wide recognition / survival across T1–T4.
- `t4-survival-by-brand.svg` — final survival rate for all 10 anonymized brands.
- `baseline-correlation.svg` — visual summary of the reported baseline-to-survival correlation. The source does not publish all raw coordinates in the aggregate page, so no individual scatter points were reconstructed.

All plotted values are explicitly reported in the source HTML. No hidden row-level observations were invented.
