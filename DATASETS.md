# Atom Foundry Research Datasets

This document provides an overview of the datasets used throughout Atom Foundry Research.

Rather than releasing isolated research papers, Atom Foundry builds a continuously growing research dataset describing how modern AI systems discover, understand, evaluate, trust and recommend ecommerce brands.

Unless stated otherwise, every published report is based on one or more of the datasets described below.

---

# Dataset Overview

| Dataset | Description |
|----------|-------------|
| AI Recommendations Dataset | Captured AI recommendations across multiple ecommerce categories. |
| AI Commerce Score Dataset | Technical evaluation of ecommerce stores using the AI Commerce Score™ framework. |
| Web Search Dataset | Recommendation experiments comparing browsing-enabled and browsing-disabled AI systems. |
| Category Research Dataset | Standardized recommendation experiments across multiple ecommerce industries. |
| Founder Lab Dataset | Public experiments documenting the creation of an AI-native ecommerce brand. |

---

# AI Recommendations Dataset

The core dataset used throughout Atom Foundry Research.

Current size

- 20,000 AI recommendations
- 1,513 unique brands
- 100 buyer-intent prompts
- 5 ecommerce categories

Captured attributes include:

- AI model
- Prompt
- Category
- Recommended merchant
- Recommendation frequency
- Experimental session

This dataset serves as the foundation for most published recommendation studies.

---

# AI Commerce Score Dataset

Technical measurements collected directly from ecommerce websites.

Current size

- 13,000+ ecommerce stores analyzed

Measured dimensions include:

- AI Readability™
- AI Understanding™
- AI Trust™
- Recommendation Intelligence™
- Decision Confidence™
- Overall AI Commerce Score™

This dataset is maintained independently from recommendation frequency, allowing direct comparison between technical readiness and AI recommendation behavior.

---

# Web Search Dataset

Controlled experiments measuring the impact of web search on AI recommendation behavior.

Typical experiments compare:

- Browsing enabled
- Browsing disabled

Variables include:

- Recommendation changes
- Vocabulary changes
- Brand selection
- Explanation consistency

---

# Category Research Dataset

Standardized recommendation experiments repeated across multiple industries.

Current categories

- Beauty
- Supplements
- Coffee
- Pets
- Home & Living

Each category follows the same experimental methodology, enabling direct comparison across industries.

---

# Founder Lab Dataset

Founder Lab is Atom Foundry's public research laboratory.

Instead of observing external brands only, Atom Foundry documents the development of its own AI-native ecommerce brand in public.

Collected observations include:

- AI understanding
- AI discoverability
- AI recommendation behavior
- Website evolution
- Public research logs

---

# Data Quality

Every published dataset follows the same quality principles.

- Real AI responses
- Real ecommerce stores
- Standardized methodology
- Manual validation
- Duplicate normalization
- Transparent documentation
