# Atom Foundry Research Datasets

This document describes the datasets used across Atom Foundry Research.

Atom Foundry maintains a growing research dataset that describes how AI systems discover, understand, evaluate, trust, select, and recommend ecommerce brands and products.

Unless a report states otherwise, published research uses one or more datasets described here.

---

# Dataset Overview

| Dataset | Description |
|---|---|
| AI Recommendations Dataset | Recorded AI recommendations across ecommerce categories and controlled experiments. |
| AI Commerce Score Dataset | Technical evaluation of ecommerce stores using the AI Commerce Intelligence™ framework. |
| Web Search Dataset | Controlled research measuring how web search changes AI recommendation behavior. |
| Mechanism Research Dataset | Controlled research designed to isolate signals and mechanisms behind AI selection and recommendation. |
| Category Research Dataset | Standardized recommendation research across multiple ecommerce industries. |
| Founder Lab Dataset | Public research documenting the creation and evolution of an AI native ecommerce brand. |

---

# AI Recommendations Dataset

This is the core recommendation dataset.

Current size:

* 40,000+ AI recommendations
* 1,490 unique brands
* 100 buyer intent prompts
* 5 ecommerce categories

Recorded fields can include:

* AI model
* Prompt
* Category
* Recommended merchant
* Recommendation frequency
* Recommendation position
* Experimental session
* Search condition
* Observed explanation

This dataset supports recommendation and selection research.

---

# AI Commerce Score Dataset

This dataset contains technical measurements from ecommerce websites.

Current size:

* 66,000+ ecommerce stores analyzed

Measured areas include:

* AI Readability™
* AI Understanding™
* AI Trust™
* Recommendation Intelligence™
* Decision Confidence™
* AI Commerce Score™

This dataset is kept separate from recommendation frequency so technical store signals can be compared with observed AI behavior.

---

# Web Search Dataset

This dataset contains controlled research on AI behavior with and without web search.

Experiments can compare:

* Browsing enabled
* Browsing disabled

Measured outcomes can include:

* Recommendation changes
* Vocabulary changes
* Brand selection
* Explanation changes
* Changes in retrieved information

The goal is to measure what changes when AI systems have access to live web search.

---

# Mechanism Research Dataset

This is a growing collection of controlled experiments designed to isolate signals and mechanisms behind AI recommendation and selection.

Research areas include:

* Candidate formation
* Final selection
* Recommendation consistency
* Previous model recommendations
* Brand fame
* Website understanding
* Ratings
* Reviews
* Web search
* Recommendation explanations
* Cross model agreement
* Multi turn behavior
* Fact deployment
* Hidden context
* Prompt shape
* Claim attribution
* Brand legibility

The dataset is designed to test individual variables instead of relying only on large scale correlations.

---

# Category Research Dataset

Standardized recommendation research is repeated across five industries.

Current categories:

* Beauty
* Supplements
* Coffee
* Pets
* Home & Living

Each category uses the same core research method so results can be compared.

---

# Founder Lab Dataset

Founder Lab is Atom Foundry's public research laboratory.

Instead of observing external brands only, Atom Foundry also documents the development of its own AI native ecommerce brand.

Collected observations can include:

* AI agent activity
* AI understanding
* AI discoverability
* AI recommendation behavior
* Website changes
* Store changes
* Rescan results
* Research logs

Founder Lab provides a long term environment for observing how controlled changes to a real ecommerce store affect AI behavior.

---

# Data Quality

Every published dataset follows these principles.

* Real AI responses
* Real ecommerce stores
* Controlled experiments
* Standardized methods
* Manual validation
* Duplicate normalization
* Transparent documentation
* Recorded observations

We separate measured results from interpretation.

Untested assumptions are not presented as findings.

---

# Availability

Dataset descriptions are public.

Individual datasets can change as new research is published.

Some complete raw datasets cannot be released.

When raw data cannot be shared, the related report documents the available measurements, method, and results.

---

# Research Scope

The research program studies the path from discovery to commercial outcome.

A simplified model is:

Discovery

↓

Understanding

↓

Candidate Formation

↓

Evaluation

↓

Selection

↓

Recommendation

↓

Commercial Outcome

Not every stage can currently be measured directly.

The research program is designed to isolate and validate the connections between these stages over time.
