# Charts

These SVGs recreate aggregate values explicitly reported on the canonical Hidden Context study page. They are intended for repository documentation and can be viewed directly in GitHub.

## Charts

- `hidden-context-overview.svg` — cohort-wide winner rate by hidden-context condition.
- `campaign-origin-by-brand.svg` — published baseline vs campaign-origin winner rate for anonymized brands.
- `condition-lift-vs-control.svg` — winner-rate lift over the 22% no-context control.
- `baseline-interaction.svg` — exploratory correlations between real-world baseline recommendation rate and hidden-context lift.

## Data boundary

The charts use reported aggregate values only. They do not imply access to unpublished row-level model responses.
