# Objective

Measure how enabling web search influences AI-generated ecommerce recommendations while keeping every other variable identical.

---

# Experimental Design

A controlled experiment was conducted using the same AI model under two conditions.

- Web Search OFF
- Web Search ON

The following variables remained unchanged:

- AI model
- Prompt wording
- Prompt order
- Product categories
- Experimental procedure

Web search was the only variable modified.

---

# Model

GPT-4o

---

# Prompt Set

50 buyer-intent ecommerce prompts covering ten product categories.

Examples include:

- Best coffee beans
- Best protein powder
- Best dog food
- Best skincare products

Each prompt was written to simulate a real purchasing decision.

---

# Experimental Procedure

Each prompt was executed repeatedly under both conditions.

For every response we recorded:

- Recommended brands
- Recommendation order
- Recommendation frequency
- Recommendation overlap
- Newly introduced brands
- Removed brands

The resulting datasets were compared to measure how recommendation behavior changed when web search became available.

---

# Metrics

Primary metrics included:

- Recommendation Change Rate
- Recommendation Overlap
- New Brand Appearance Rate
- Brand Disappearance Rate
- Category-level Change Rate

---

# Limitations

Results represent the behavior of GPT-4o at the time of testing.

Future AI model updates may produce different recommendation patterns.
