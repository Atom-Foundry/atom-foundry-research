# Charts

SVG charts derived from the published Prompt Shape study.

- `winner-rate-by-length.svg` — pooled winner rate by the five prompt-length levels.
- `winner-rate-by-sentence-type.svg` — pooled winner rate by declarative, question, and imperative forms.
- `winner-rate-by-persona.svg` — pooled winner rate by the seven tested writer-style personas.

All values use the final gpt-4o LLM-judge scoring reported in the study.
