# Charts

Charts for **Study #28 — The Model Had Real Web Search. It Never Once Reached for It.**

## Included charts

- `search-invocation-rate.svg` — search-tool invocation for the 960 open buyer-question calls versus the 3-prompt diagnostic.
- `live-search-mention-rate.svg` — live-search mention rate for the four anonymized brands.
- `realized-ceiling.svg` — realized share of the Fact Injection ceiling, using the study's stated formula.
- `baseline-live-injected.svg` — published baseline, live-search condition, and injected ceiling on one mention-rate axis.

## Source

All plotted values are explicitly reported in the published HTML study. No row-level observations were reconstructed or invented.
