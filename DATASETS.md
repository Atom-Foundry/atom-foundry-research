# Atom Foundry Research Datasets

This document provides an overview of the datasets used throughout Atom Foundry Research.

Rather than releasing isolated research papers, Atom Foundry builds a continuously growing research dataset describing how modern AI systems discover, understand, evaluate, trust, select and recommend ecommerce brands and products.

Unless stated otherwise, every published report is based on one or more of the datasets described below.

---

# Dataset Overview

| Dataset | Description |
|----------|-------------|
| AI Recommendations Dataset | Captured AI recommendations across multiple ecommerce categories and controlled experiments. |
| AI Commerce Score Dataset | Technical evaluation of ecommerce stores using the AI Commerce Intelligence™ framework. |
| Web Search Dataset | Controlled experiments measuring how web search changes AI recommendation behavior. |
| Mechanism Research Dataset | Controlled experiments designed to isolate signals and mechanisms behind AI selection and recommendation. |
| Category Research Dataset | Standardized recommendation experiments across multiple ecommerce industries. |
| Founder Lab Dataset | Public experiments documenting the creation and evolution of an AI-native ecommerce brand. |

---

# AI Recommendations Dataset

The core dataset used throughout Atom Foundry Research.

Current size

- 40,000+ AI recommendations
- 1,490 unique brands
- 100 buyer-intent prompts
- 5 ecommerce categories

Captured attributes include:

- AI model
- Prompt
- Category
- Recommended merchant
- Recommendation frequency
- Recommendation position
- Experimental session
- Search condition
- Observed explanation

This dataset serves as the foundation for published recommendation and selection studies.

---

# AI Commerce Score Dataset

Technical measurements collected from ecommerce websites.

Current size

- 66,000+ ecommerce stores analyzed

Measured dimensions include:

- AI Readability™
- AI Understanding™
- AI Trust™
- Recommendation Intelligence™
- Decision Confidence™
- Overall AI Commerce Score™

This dataset is maintained separately from recommendation frequency, allowing research to compare technical store characteristics with observed AI recommendation behavior.

---

# Web Search Dataset

Controlled experiments measuring the impact of web search on AI recommendation behavior.

Experiments compare conditions such as:

- Browsing enabled
- Browsing disabled

Variables include:

- Recommendation changes
- Vocabulary changes
- Brand selection
- Explanation changes
- Search-driven changes in retrieved information

The purpose is to measure what changes when AI systems are given access to live web search.

---

# Mechanism Research Dataset

A growing collection of controlled experiments designed to identify the signals and mechanisms behind AI recommendation and selection.

Research areas include:

- Candidate formation
- Final selection
- Recommendation consistency
- Previous model recommendations
- Brand fame and prominence
- Website understanding
- Ratings
- Reviews
- Web search
- Recommendation explanations
- Cross-model agreement
- Longitudinal recommendation behavior

The dataset is designed to isolate individual variables rather than relying only on correlations observed in large datasets.

---

# Category Research Dataset

Standardized recommendation experiments repeated across multiple industries.

Current categories

- Beauty
- Supplements
- Coffee
- Pets
- Home & Living

Each category follows the same core experimental methodology, enabling direct comparison across industries.

The category datasets provide the basis for cross-category analysis in the flagship research.

---

# Founder Lab Dataset

Founder Lab is Atom Foundry's public research laboratory.

Instead of observing external brands only, Atom Foundry documents the development and evolution of its own AI-native ecommerce brand in public.

Collected observations include:

- AI agent activity
- AI understanding
- AI discoverability
- AI recommendation behavior
- Website changes
- Store changes
- Rescan results
- Public research logs

The Founder Lab provides a longitudinal environment for observing how controlled changes to a real ecommerce store affect AI behavior.

---

# Data Quality

Every published dataset follows the same quality principles.

- Real AI responses
- Real ecommerce stores
- Controlled experiments
- Standardized methodology
- Manual validation
- Duplicate normalization
- Transparent documentation
- Recorded observations

We distinguish measured results from interpretation and do not present untested assumptions as findings.

---

# Availability

Datasets are described publicly as part of the Atom Foundry Research initiative.

Individual datasets may evolve over time as new research is published and additional observations are collected.

Where complete raw datasets cannot be released, the corresponding methodology, measurements and experimental results are documented in the published research.

---

# Research Scope

The datasets are used to study the progression from discovery to selection.

A simplified model is:

Discovery  
↓  
Understanding  
↓  
Candidate Formation  
↓  
Evaluation  
↓  
Selection  
↓  
Recommendation  
↓  
Commercial Outcome

Not every stage can currently be measured directly.

The research program is designed to progressively isolate and validate the mechanisms connecting these stages.
