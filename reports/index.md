## ⚙️ Mechanism Studies

Research explaining why AI recommendation systems behave the way they do.

| Report | Focus |
|---|---|
| Web Search Changes AI Recommendations | Measuring how web search changes recommendation behavior. |
| The Fame Study | Measuring how public fame signals relate to recommendation frequency. |
| AI Knows Your Website | Measuring how accurately AI identifies a brand's official website. |
| AI Confabulates Its Reasons | Testing whether AI explanations reliably describe its decision mechanism. |
| Search Changes the Vocabulary | Measuring how browsing changes the information language used by AI. |
| Candidacy vs Selection | Separating entry into the consideration set from final brand selection. |
| The Model Predicts Itself | Measuring how previous model outputs relate to future recommendations. |
| Recommendation Lock-In | Testing stability of recommendations across repeated runs and time. |
| Candidate Evaluation | Testing whether controlled ratings, specifications, and price changes alter selection. |
| Cold Start | Testing whether a new brand can enter recommendations without established history. |
| Memory Source | Testing multiple public fame signals against the model's own behavior. |
| Recommendation Confidence | Testing whether verbal hedging tracks actual recommendation confidence. |
| Possession vs Deployment | Testing which known brand facts are actually deployed in recommendation decisions. |
| Multi-Turn Displacement | Testing whether an initial recommendation survives a multi-turn shopping conversation. |
| Fact Injection | Testing whether injecting a missing verified fact changes recommendation behavior. |
| Hidden Context | Testing whether contextual information can shift recommendation outcomes. |
| Accuracy Depth | Measuring how accurate versus detailed AI understanding of brands is. |
| Live Retrieval | Testing whether live web retrieval changes how a model reaches brand information. |
| Brand Legibility | Testing whether a brand can become recommendable from a clear, verified description. |
| Prompt Shape | Testing how prompt length, sentence type, and writing style affect recommendation outcomes. |
| Claim Attribution | Testing whether self-claimed versus third-party claims change recommendation selection. |

# Research Focus

Our work explores how modern AI systems:

- discover brands
- understand websites
- evaluate products
- build trust
- generate recommendations
- explain decisions
- change behavior when web search is available
- behave across multi-turn conversations
- use facts they already possess
- deploy only some of the facts they know
- respond to controlled changes in context and prompts
- influence commercial outcomes

Rather than studying visibility alone, we study the complete recommendation process.

---

# Research Principles

Every published report follows the same principles.

- Real AI responses
- Real ecommerce stores
- Transparent methodology
- Reproducible experiments
- Independent analysis
- No synthetic datasets
- No sponsored conclusions

If we cannot measure it, we do not publish it.

# Research Thesis

The first generation of AI commerce focused on visibility.

The next generation will focus on recommendation.

Being discovered is not the same as being recommended.

Being recommended is not the same as being chosen.

Atom Foundry exists to understand the difference.
